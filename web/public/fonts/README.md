# Website fonts

Fetched 2026-09-29 from the Google Fonts CSS API and served locally.
`typography.css` keeps the supplied Latin unicode ranges (including Spanish accents).
`sources.json` records immutable font URLs, SHA-256 hashes and byte sizes.
Each family has its original SIL Open Font License alongside it.
No font request to Google or another third party happens in the browser.

- Fraunces:opsz,wght,SOFT,WONK@9..144,100..900,50,1 — `fraunces-OFL.txt`
- Source Sans 3:wght@200..900 — `sourcesans3-OFL.txt`
